# VIGIROAD 1.3 — mises à jour automatiques

## 1.3.0

- Mises à jour automatiques directement depuis l'application, sans Play Store ni navigateur
- Nouvelle version détectée au démarrage puis toutes les 6 heures
- Téléchargement vérifié (empreinte SHA-256) et installation confirmée par Android
- Jamais d'interruption pendant un guidage : la fenêtre attend l'arrivée

## Première installation de la 1.3.0

Les versions 1.2.x ne contiennent pas encore le système de mise à jour : installer la 1.3.0 une
dernière fois à la main (par-dessus la 1.2.x, même signature). Les versions suivantes seront
proposées directement dans l'application.
